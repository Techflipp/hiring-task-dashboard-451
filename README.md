# TechFlipp Frontend Task

## Requirements

### 1. Camera List Page

- Implemented a paginated view of cameras
- Added filter camera based on URL params
- Made it as a server side rendered for better SEO and performance
- Implemented Next.js caching mechanism for better performance.

### 2. Camera Detail Page

- Created a view showing comprehensive camera information
- Made this page server side rendered for better performance and SEO
- Added edit details feature and proper form validations
- Enabled users to create or edit demographics configuration for cameras - one to one relationship with camera

### 3. Demographics Results & Analytics

- Implemented filtering capabilities for the data using URL params.
- Created informative visualizations using chart.js.
